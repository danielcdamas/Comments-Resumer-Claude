        Contagem direta das palavras, sem IA: em quantos comentários cada termo aparece.

          Os comentários são lidos pela YouTube Data API e analisados pelo Gemini. Nada é armazenado no servidor.

          Configurações

          As chaves ficam guardadas apenas neste navegador. A cada análise, elas passam pelo servidor desta ferramenta só para serem repassadas ao Google, sem nenhum armazenamento. Deixe em branco para usar as chaves configuradas no servidor, se houver.

          Como obter as chaves
          1. Gemini: acesse aistudio.google.com/apikey e copie sua chave.
          2. YouTube: no Google Cloud Console, clique em "Ativar" na YouTube Data API v3 e, em "Credenciais", crie uma chave de API. Ela pode ser diferente da chave do Gemini: basta colar cada uma no seu campo.
          3. A cota gratuita do YouTube permite cerca de 10.000 páginas de 100 comentários por dia.
